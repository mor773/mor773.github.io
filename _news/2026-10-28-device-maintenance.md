## 日常巡检

1. 查看设备是否在线。
2. 检查温度、湿度与土壤含水率。
3. 点击预警，定位异常采集点。

## 调整告警阈值

本公司开发者可在设备详情页修改阈值，保存后重新计算当前读数的预警状态。

```json
{
  "soilMoisture": {
    "min": 30,
    "max": 75
  }
}
```

> 网页阈值修改仅保存在当前浏览器，不会下发到真实设备。

## 离线设备

离线设备显示最后一次模拟采样。请先确认供电、网络与采集终端状态，再判断传感器读数。
